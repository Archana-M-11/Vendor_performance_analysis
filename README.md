# Vendor_performance_analysis

## 📌 Project Overview
This project focuses on analyzing vendor performance using **Python, SQL, and Power BI** to identify sales trends, profit margins, vendor efficiency, and low-performing vendors/brands.

The analysis helps businesses understand:
- Vendor contribution to sales
- Top-performing vendors and brands
- Profitability trends
- Low-performing vendors and brands
- Purchase contribution and business insights

---

## 🚀 Project Objectives
The main objectives of this project are:

- Analyze vendor sales and purchase performance
- Identify top and low-performing vendors
- Calculate estimated profit and profit margins
- Analyze unsold capital
- Create an interactive Power BI dashboard for business insights
